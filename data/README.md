# Dataset

This project uses the **Dengue Dataset Bangladesh** from Kaggle.

## Dataset Source

- Dataset Name: Dengue Dataset Bangladesh
- Source: Kaggle
- Author: Kawsar Ahmad
- Link: https://www.kaggle.com/datasets/kawsarahmad/dengue-dataset-bangladesh

## Usage in This Research

This dataset was used for developing and evaluating the AI + IoT-Based Early Prediction and Prevention System for Dengue.

The dataset supports dengue risk analysis, location-based prediction, and early outbreak prevention research.

## Important Notice

The original dataset is **not redistributed in this repository**.

Please download the dataset directly from Kaggle and place it inside this folder before running the project.
